# NewDay

NewDay 是一个本地优先的每日任务清单。它只关注“哪几天需要看到这件事”，不再提供小时级时间轴。

## 核心功能

- 桌面端采用左右分栏：左侧显示大号当前时钟，右侧专注每日任务
- 周日期导航紧跟时钟与日期，下方保留当日待办/完成概览和固定寄语
- 支持亮色与暗色模式：首次跟随系统，手动切换后在当前浏览器中记住选择
- 使用左右箭头按天切换，也可以通过日期选择器直接跳转
- 任务只保留开始日期和截止日期，两个日期默认都是当前选中的当天
- 任务会显示在开始日期到截止日期之间的每一天，日期范围包含首尾两天
- 支持快速添加、编辑、完成、恢复和删除任务
- 今天会继续显示逾期未完成任务，并可选最多三项“今日重点”
- 支持每天、工作日、每周指定星期和每月重复；每月 29/30/31 日自动夹到月末
- 重复实例可以单独编辑或改期，也可以从当前实例开始更新或停止后续重复
- 完成、恢复、删除和改期后可在 10 秒提示窗口内撤销
- 导入与导出收纳在右上角“更多”菜单中；替换导入前自动下载当前数据备份
- 数据保存在当前浏览器的 IndexedDB 中，无需账号
- 旧版单日任务会自动迁移为开始日期和截止日期相同的任务

## 本地开发

要求：Node.js 20+、pnpm 10+。

```bash
pnpm install
pnpm dev
```

打开 <http://localhost:3000>。

## 验证

```bash
# ESLint + TypeScript + Vitest
pnpm check

# Chrome 与 Safari WebKit 端到端测试
pnpm test:e2e

# 生产构建
pnpm build
```

首次运行端到端测试时，如本机尚未安装 Playwright 浏览器：

```bash
pnpm exec playwright install chrome webkit
```

## 架构

核心代码位于 `src/modules/planner/`：

- `domain/`：`Task`、重复规则、日期范围及 Zod 领域校验
- `application/`：任务命令、重复实例生成、每日分组查询、瞬时撤销、备份与恢复
- `adapters/`：Dexie/IndexedDB Store 与内存测试 Store
- `ui/`：大时钟、日期导航、每日任务列表与任务编辑器

所有修改都通过 `PlannerCommand` 进入 Store，并在事务中执行。应用层统一负责正常日期范围、今日逾期投影、今日重点去重、重复实例生成和稳定分组排序。

领域词汇记录在 [`CONTEXT.md`](./CONTEXT.md)。

## 数据与备份

NewDay 不会把任务上传到服务端。清除浏览器站点数据会删除本地任务，因此建议定期使用右上角“导出”。

新版导出格式版本为 `3`，包含任务、重复系列和今日重点记录。导入仍兼容旧版 `1` 与 `2` 格式：旧任务会补齐日期范围与完成日期字段，重复系列和重点记录保持为空。
