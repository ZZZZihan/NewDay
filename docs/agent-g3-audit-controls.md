# COL-23：逐次留证与金额控制补充

本说明补充 [G3 逐次试验协议](./agent-g3-trial-protocol.md) 的执行工具，不修改场景、期望答案、提示词、schema、人评维度或通过标准，也不是调用许可。历史单条 H-N01 的批准不适用于完整批次。启动真实调用仍要求用户确认新的候选 SHA、发送范围、请求与金额上限及停止条件，并据此生成新的私有 freeze。

## 可重复的合成快照

评测 helper 在内存 SQLite 中通过生产 context/preferences 服务构建快照。仅评测用的 dataset epoch 和 snapshot ID 从带版本的 scenario ID 与 input 摘要确定；不使用 expected 答案，不改变生产业务 ID。这样独立 CLI 进程可重建逐字相同的 H-P05 快照，使人工批准的澄清映射可以续跑。机械适配写入每条报告。历史随机 ID 的 pilot 保留原证据，不能混作本批次结果。

## 原始响应与边界

G3 为 provider adapter 安装可选 audit 回调。请求正文在发送前独立落盘；HTTP 200 的响应原文在 JSON/合同解析前落盘，因此语法错误、错误 envelope、截断或宿主拒绝均可审计。逐次报告仍区分原始输出、合同校验与最终结果。旁路文件包含 trial ID、调用序号和记录时间；目录为 0700，文件为 0600，只在仓库外的私有证据目录写入。

Authorization header 和 API key 不落盘；若响应回显凭据则脱敏并标记。沿用原协议，非 2xx 的原始错误正文不保留，记录实际 HTTP 状态与 `omitted_http_error`，不把缺失正文伪装成完整原始响应。超过现有 200,000 字节响应上限仅保留有界前缀并标记 `truncated`；中断标记 `interrupted`。没有收到响应时记录无响应。缺失或不可核验用量时不填零费用。

审计写失败会作为整批故障中止，不能被当作模型格式问题触发修复请求。每条 CLI 命令仍只执行一个场景/重复序号，后续命令继续要求当前账本 SHA 与上条证据复核。H-P05 的语义映射和所有人工评分仍由指定真人完成，Agent 的结构检查不冒充人评。

## 费用预留

freeze v3 新增 `metered_upper_bound` 费用模式；v2 保留历史兼容，但不能使用这个新模式。冻结金额币种、总额、每次请求的最坏预留、输入 token 上界、输入/输出单价及价格出处。每次请求先原子持久化最坏费用预留，只有剩余预算足够才允许出站。收到可信的非负安全整数 token 用量后，按冻结的保守价格向上取整到微元并结算预留；缓存折扣和闲时折扣不用于扩大授权预算。账本中的结算明细防止重复释放同一调用的预留。

若用量未知、超出冻结 token 上界，或价格/模型信息漂移，保留最坏预留并停批。进程崩溃也保留未结算预留。金额记录区分保守 token 费用上界与提供方实际扣款；未经账单核对不能声称实际扣款已经确认。提供方若违反声明的 token 限制或冻结价格，停止并报告该异常，不能虚构本地程序能控制外部账单。

例如按 DeepSeek 公布的 1M 上下文采用更保守的 1,048,576 输入 token 上界、1,200 输出 token 上限，以及高峰未命中输入 ¥2/百万、输出 ¥8/百万，单次最坏费用为 ¥2.106752，可预留 ¥2.11。总预算若为 ¥5，则只有已结算上界加下一次 ¥2.11 仍不超过 ¥5 时才继续。最终金额与日期应以当次用户批准的私有 freeze 为准。价格来源：[DeepSeek 官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。

## 请求数量与结论

原始 G3 分母保持 40 场景 × 3 = 120 trial。当前生产路径对 H-C04（全部阻塞）和 H-P02（没有当前候选）直接返回宿主 `no_action`，共 6 条零出站 trial；报告须单列，不能说它们产生了模型输出。其余 38 × 3 = 114 条有首轮出站。普通 trial 最多首轮与一次修复，H-P05 的三个 trial 各最多三次请求（含人工放行的澄清）；该冻结语料与执行路径的总出站上界为 37 × 3 × 2 + 3 × 3 = 231。

保留集仓库可见，不是盲测；模型 alias 只能核对 provider 返回的模型 ID 及可用的 fingerprint，不能证明提供方内部权重从未在同一 alias 下变化。遇到明确漂移停止。报告应同时保留全部 120 条计划记录、实际出站数、宿主零调用数和所有失败/待裁定条目，不以补跑替换失败，不把脚本执行完毕或本地检查通过说成 G3/G4 完成。
